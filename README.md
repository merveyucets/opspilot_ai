# OpsPilot AI

**Akıllı Müşteri Destek ve İade Süreci Asistanı** — BTK Akademi Yapay Zekâ Çözümleri Kariyer Geliştirme Atölyesi bitirme projesi.

Müşteri destek uzmanlarına gelen iade, garanti ve şikâyet taleplerini kurumsal politika dokümanları üzerinden **yerel RAG** ile analiz eden, ilgili prosedürü **kaynak göstererek** çözüm öneren ve yanıt taslağı hazırlayan; son kararı **insan onayına** bırakan bir AI agent sistemi.

**Teknolojiler:** Ollama (yerel LLM + embedding) · LangChain · ChromaDB · LangGraph · MCP · FastAPI · n8n (Docker)
